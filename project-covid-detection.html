COVID-19 Chest X-ray Detection

A binary image classification project for educational chest X-ray analysis

Overview

This project uses deep learning to classify chest X-ray images into two categories: COVID Positive and Normal. It is built around TensorFlow and MobileNetV2 transfer learning, with a lightweight preprocessing and inference pipeline designed for both desktop GUI use and CLI-based testing.

The workflow is intentionally simple: upload an image, preprocess it to the required input size, run it through the model, and display the predicted class with a confidence score.

Disclaimer: this project is for educational purposes only and should not be used for real medical diagnosis.

Key Features

  • Image Upload: Tkinter-based desktop interface for selecting and analyzing chest X-ray images
  • Fast Inference: Predicts classes quickly and displays the confidence score for each result
  • Background Processing: Keeps the UI responsive while the model is running
  • CLI Support: Run predictions from the command line for quick testing and validation
  • Transfer Learning: MobileNetV2 is used as the base model to speed up training and improve performance
  • Reusable Pipeline: Includes preprocessing, training, and prediction components for easy extension
  • Binary Output: Focused on two classes only: COVID Positive and Normal

How It Works

1. Image Input: The user uploads a chest X-ray image through the GUI or passes a file path through the CLI.

2. Preprocessing: The image is resized to 224 × 224, normalized, and prepared in the format expected by MobileNetV2.

3. Prediction: The trained model produces a binary classification output with a confidence score.

4. Result Display: The app shows whether the image is predicted as COVID Positive or Normal.

Model Details

Architecture

MobileNetV2 transfer learning for efficient feature extraction and binary classification.

Input Size

224 × 224 × 3 images, normalized before inference and training.

Optimizer

Adam optimizer for stable and practical training behavior.

Loss Function

Binary cross-entropy for two-class classification.

Output

COVID Positive or Normal with a confidence percentage.

Interface

Tkinter desktop app plus command-line prediction script.

Dataset Notes

The dataset is not included in the repository because of its size. The expected source is the COVID-19 Radiography Database from Kaggle, organized into separate COVID and Normal folders with image subdirectories.

This makes it easy to retrain the model locally while keeping the repository lightweight.

Limitations & Future Work

The project currently focuses on only two classes, does not include advanced evaluation metrics in the basic version, and assumes a fixed input image size.

Future improvements could include class balancing, richer evaluation reporting, fine-tuning the backbone further, Docker packaging, and web deployment for broader accessibility.
